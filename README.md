# ✈️ Strategic Airline Market Analysis: Pricing, Volume and Dominance using SQL

## 📌 Project Description

This project performs a strategic analysis of the Indian airline industry using SQL.

The objective is to analyze airline pricing strategies, revenue patterns, passenger demand, route dominance, and competitive positioning between premium and low-cost carriers.

By analyzing 15,000+ flight records, this project uncovers how airlines position themselves in the market and how travelers can optimize booking decisions through smarter timing and route selection.

The insights generated support better pricing strategies, optimized scheduling, and revenue-focused decision-making.
